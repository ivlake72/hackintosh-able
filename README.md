# Hackintosh-Able
A Python-based program to check if your PC is suitable for a Hackintosh installation.

### ⚠️ Disclaimer
- This project is currently in beta, so there might be some bugs. If you notice anything wrong, feel free to open an Issue!

This program checks your hardware as follows:
- CPU
- GPU
- Motherboard
- Audio

---

PC가 Hackintosh 설치에 적합한지 확인하는 Python 기반 프로그램입니다.

### ⚠️ 알림
- 이 프로젝트는 아직 베타 단계라 오류가 있을 수 있습니다. 버그나 개선 사항이 있다면 Issue로 남겨주세요!

이 프로그램은 다음과 같이 하드웨어를 검사합니다.
- CPU
- GPU
- 마더보드
- 오디오
